osu! farm finder

自分と似たプレイヤーは pp を稼いでいるのに、自分はまだ稼げていない譜面を探します。

初回は、250人で4〜5分かかります（osu! に負担をかけないよう、問い合わせを1秒に1回程度に抑えているためです）。 取得したデータはこのパソコンに一時保存されるので、2回目以降はすぐに終わります。

  1. プレイヤー情報
  2. あなたのベストスコア
  3. ランキング
  4. pp が近いプレイヤーのベストスコア

    設定：osu! API クライアント

    このツールは、osu! の公式 API を使ってデータを取得します。使うには、あなた専用の「クライアントID」と「クライアントシークレット」が必要です（無料）。

    1. osu! にログインし、アカウント設定の「OAuth」欄を開きます。
    2. 「新しいOAuthアプリケーション」を押し、名前に osu-farm-finder、コールバックURLに http://localhost と入力して登録します。
    3. 表示されたクライアントID（数字）とクライアントシークレットを、下に入力します。

    入力内容はこのパソコンの中にだけ保存され、osu! 以外には送信されません。保存したシークレットは画面に表示しません。
